TASK 3 — INTERACTIVE WEB ELEMENTS


JavaScript concepts demonstrated:
- document.getElementById() — selects an HTML element.
- addEventListener() — runs code after a user event such as click or submit.
- textContent / innerHTML — updates displayed content.
- classList.toggle() — switches a CSS class on or off.
- preventDefault() — prevents a form submission from refreshing the page.
- if statements and variables — handle input and keep track of the counter.
