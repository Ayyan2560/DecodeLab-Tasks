# Northbound — Static Webpage Design

A responsive static landing page celebrating scenic destinations in northern Pakistan.

## Files
- `index.html` — semantic page structure and content
- `style.css` — layout, typography, colors, hover effects, and responsive breakpoints

## Notes
- This is a static HTML/CSS project; no JavaScript or build tools are required.
- Google Fonts and photographs are loaded from the internet, so an internet connection is needed to see the chosen typefaces and photographs.
- Photo credits and source links are included in the footer.
