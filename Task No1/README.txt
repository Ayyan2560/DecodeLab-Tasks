RESPONSIVE WEB LAYOUT - PROJECT 2

Files:
- index.html: webpage structure and content
- style.css: styling, layout, and responsive media queries

How to run:
1. Extract the ZIP file.
2. Open the responsive-web-layout folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Resize the browser window or use browser developer tools to test mobile, tablet, and desktop widths.

Key skills demonstrated:
- CSS Flexbox and Grid
- Responsive navigation using a CSS-only checkbox toggle
- Media queries at 900px, 700px, and 420px
- clamp() for fluid typography
- Responsive spacing and card layouts
- Semantic HTML sections and accessible labels
